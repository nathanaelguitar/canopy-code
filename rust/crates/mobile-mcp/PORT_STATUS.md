# `packages/mobile-mcp` Rust port status

The Rust workspace crate provides a native MCP runtime and device adapters for
the mobile-MCP surface. Cargo exposes `canopy-mobile-mcp` as the Canopy command,
while keeping `mcp-server-mobile` and `mobile-mcp` executable aliases. The npm
package keeps its `@qwen-code/mobile-mcp` name, version, metadata, and
`mcp-server-mobile` command. That command now enters through a small Node
launcher which selects `native/<platform>-<arch>/mcp-server-mobile[.exe]` and
passes arguments and stdio through to Rust. In a source checkout without a
bundled artifact, it runs the same Cargo binary from the workspace. `npm run
build` continues to compile the TypeScript entrypoint as the oracle; `prepack`
also builds a native artifact for the current host by default. Set
`MOBILE_MCP_TARGETS` to a comma-separated list of supported package target keys
to build more artifacts when the corresponding Rust target toolchains are
available. The TypeScript package remains the behavior oracle for the listed
differences.

The SSE listener stops accepting connections on SIGINT, SIGTERM, or SIGHUP,
closes the active event stream, and joins its stream writer before returning.
An in-progress POST/tool call completes under its existing bounded timeout
before the accept loop observes shutdown. Stdio stops reading on the same
signals, drains already accepted calls, flushes queued responses, and drops its
`MobileServer` so active recordings are terminated; an idle stdin reader is not
joined during signal shutdown and exits with the process. Synchronous commands
launched by `CommandRunner::run` have a 30-second deadline
and an 8 MiB retained-output ceiling; stdout and stderr are drained concurrently
so a full pipe cannot deadlock the parent. Unix commands run in a private process
group, and timeout cleanup kills helper processes that inherit the pipes. The
separate background recording process is intentionally long-running; naturally
completed recordings are reaped from the active map before the next tool call,
and explicit stop or server shutdown terminates active recordings. A Unix reliability
check covers output overflow and timeout termination. The stdio worker keeps one
`MobileServer` alive for the session, so queued calls retain recording and
simulator state; EOF drains accepted calls, then drops the server and terminates
any active recording through its normal cleanup. The bounded stdio work queue
holds four waiting frames (plus the active frame); requests that arrive while
full receive a `-32603` busy error with their original ID, while no-ID
notifications are dropped. The SSE listener
requires an exact optional Bearer token, rejects requests with an Origin header
and all OPTIONS requests, limits the server to one active GET stream, and
forwards POSTed JSON-RPC replies over that stream. It sends a heartbeat every
ten seconds and expires stalled socket operations after fifteen seconds.
Direct dependencies are `base64`, `ctrlc`, `regex`, `reqwest` (blocking
telemetry client), `serde`, `serde_json`, `sha2`, `uuid`, `wait-timeout`, `zip`,
and Unix-only `libc`. Existing Rust unit tests cover protocol negotiation,
request validation, bounded command execution, SSE parsing/auth/limits, and a
loopback exchange; tests and native device automation were not run for this
porting slice. The package was checked with Cargo, and changed Rust sources were
formatted and whitespace-checked.

The npm command is wired to Rust, but release distribution still needs a target
matrix. The launcher/build script recognize `darwin-arm64`, `darwin-x64`,
`linux-arm64`, `linux-x64`, `win32-arm64`, and `win32-x64`; Linux artifacts use
the GNU ABI. Only targets actually built and included under `native/` are
available in a published tarball. The default `prepack` builds only the pack
host, so release automation must stage/aggregate every intended artifact before
publishing. This slice successfully built the macOS ARM64 release executable,
compiled the TypeScript oracle, and confirmed with `npm pack --dry-run` that
the launcher and that native artifact are included in the `0.20.1` package.
The binary itself was not run as part of the build-only verification. No
cross-platform build or target package installation has been verified here. In
particular, Windows, Intel macOS, Linux ARM64, and the non-host targets remain
unverified; musl Linux has no artifact mapping. The release still needs
per-target packed-package checks for launcher selection,
argument/stdin/stdout/stderr/exit-code forwarding, and version/help output, plus
package parity and physical-device acceptance on supported Android and iOS
configurations. Hardware-specific driver results cannot be inferred from the
source-level port. The direct package `main` remains `lib/index.js` for
TypeScript-oracle compatibility; the npm executable command is the Rust
cutover point.
